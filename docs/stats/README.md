## 시도별 생산 통계 (2026-10-13)
| 결과 파일 | 원자료 | 만드는 법 | 앱 화면 |
|---|---|---|---|
| `regional_crops.csv` | 통계청 「농작물생산통계」 2007–2017·2023년판의 '연도별(최근 5개년) 시·도별 농작물 생산량' 표 → 2003–2017·2019–2023 시도별 재배면적·10a당 생산량·생산량(약 85품목). 농식품부 「2024 특용작물 생산실적」 시도별·품목별 표 → 2024 시도별 농가 수·면적·생산량(약 90품목) | `python -I docs/stats/parse_regional.py data/raw/kosis/_txt docs/stats` — 연도 줄·항목 줄과 품목 이름 줄을 화면 칸(한글 2칸)으로 맞춰 열을 정함. 같은 연도는 최신 책 값. 시도 합 = 전국 확인: 5,877묶음 중 28묶음만 1–3% 차(모두 반올림) | 소재 화면 '시도별 생산'(`regional_crops_map.json`: 종 학명 → 품목, 93계열) |

- 텍스트는 PC 에서 `pdftotext -layout` 으로 만든다(`data\raw\kosis\_txt\`). **2018–2022년판 농작물생산통계·2024년판 농작물생산통계, 2019–2023년판 특용작물 생산실적은 스캔본(글자 없음)** 이라 쓰지 않았다 → 2018년 값과 농작물 2024년 값이 비어 있다(2023년판이 2019–2023 을 담음).
- 특용작물 시도별 표는 2024판만 쓴다(2014–2018판은 표 머리가 해마다 달라 열 이름이 어긋남). 특용작물 전국 추이는 `special_crops_annual.csv`(경작지 기준).
- **KOSIS 통계표(xlsx, 2026-10-14 내려받음)** 를 셋째 인자로 주면 함께 읽고 책보다 앞에 둔다: 과실·두류·미곡(백미 92.9%) 2025, 과채류·잡곡·특용작물 2024, 맥류·서류·조미채소(마늘·양파) 2026 등 최신 연도. 조곡·현미·백미 90.4%·성과수미과수·주산지 시군·시군별 논벼·표본오차 표는 읽지 않음. 2024 특용작물은 책 파싱 값과 KOSIS 값이 7,809/7,920칸 일치('기타' 묶음·단수 반올림만 다름) → 책 파싱 검증으로도 씀.
  `python -I docs/stats/parse_regional.py data/raw/kosis/_txt docs/stats data/raw/kosis`
- 적재: `python -m scripts.load_regional_crops` (load_food_materials 끝에서도 자동)
